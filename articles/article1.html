在 Windows 里原生安装 openclaw

发表于 2026 年 3 月 10 日

引言

以下是详细步骤

正文

安装winget 1.信任 PSGallery 仓库： Set-PSRepository -Name 'PSGallery' -InstallationPolicy Trusted 2.安装脚本： Install-Script -Name winget-install -Force 3.运行脚本安装 Winget： winget-install 插曲：如果powershell受限，运行Set-ExecutionPolicy RemoteSigned 系统会提示确认，输入Y并按Enter 4.验证 winget --version 1: 安装最新 LTS 版的 Node.js（v24.x，目前的最新 LTS 版） 在 PowerShell 或命令提示符（CMD）中运行以下命令（以管理员身份打开）： winget install -e --id OpenJS.NodeJS.LTS 2.安装后，重启PowerShell，验证版本： node -v 3.安装 Git： winget install --id Git.Git -e --source winget 重启PowerShell，验证 Git git --version 4.安装 OpenClaw 在 PowerShell/CMD 或 WSL 终端中运行： npm install -g openclaw@latest 5.验证： openclaw --version
