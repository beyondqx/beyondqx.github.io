# beyondqx 的博客

基于 React + GitHub Discussions 的轻量级博客系统。

**博客地址**: https://beyondqx.github.io

## 快速开始

```bash
# 安装依赖
npm install

# 本地开发
npm start

# 构建部署
npm run build
npm run deploy
```

## 配置

1. 复制 `.env.example` 为 `.env`
2. 填入你的 GitHub OAuth Client ID

## 功能

- GitHub OAuth 登录
- 文章管理（新建/编辑/删除）
- Markdown 编辑器
- 评论系统
- 深色模式
